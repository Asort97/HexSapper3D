# HexSapper3D

Трёхмерная игра-головоломка "Сапёр" на гексагональной сетке, разработанная на Unity.

## 📋 Описание проекта

HexSapper3D - это современная интерпретация классической игры "Сапёр" с использованием гексагональной сетки вместо традиционной квадратной. Игра реализована в 3D с поддержкой кампании, системой рейтингов и интеграцией с Yandex Games.

### Основные особенности

- **Гексагональная сетка** - уникальная игровая механика с шестиугольными ячейками
- **Кампания** - прогрессивная система уровней с увеличивающейся сложностью
- **Система рейтингов** - отслеживание прогресса игрока и достижений
- **Таймер** - ограничение по времени для дополнительного вызова
- **Визуальные эффекты** - плавные анимации и частицы для улучшения игрового опыта
- **WebGL поддержка** - возможность запуска в браузере через Yandex Games

## 🛠️ Стек технологий

### Движок и среда разработки
- **Unity** 2023.2.17f1
- **Universal Render Pipeline (URP)** 16.0.5
- **C#** - основной язык программирования

### Основные пакеты Unity
- `com.unity.ugui` 2.0.0 - пользовательский интерфейс
- `com.unity.timeline` 1.8.6 - кинематографические эффекты
- `com.unity.ai.navigation` 2.0.0 - навигация AI
- `com.unity.2d.sprite` 1.0.0 - работа со спрайтами
- `com.unity.test-framework` 1.3.9 - тестирование

### Внешние библиотеки
- **DOTween** - система анимации и твининга
  - Используется для плавных переходов камеры
  - Анимация UI элементов (панели победы, кнопки)
  - Анимация игровых объектов (флаги, ячейки)

- **UniTask** (Cysharp.Threading.Tasks) - асинхронное программирование
  - Управление асинхронными операциями
  - Задержки и последовательности действий
  - Цепочки взрывов мин

- **TextMesh Pro** - продвинутая система текста
  - Рендеринг текста в UI
  - 3D текст на игровых объектах
  - Градиентные эффекты текста

- **Yandex Games SDK (YG)** - интеграция с платформой Yandex Games
  - Сохранение прогресса
  - Лидерборды
  - WebGL деплой

- **Cartoon FX Remaster (JMO Assets)** - визуальные эффекты
  - Эффекты взрывов
  - Частицы победы

- **Linework Lite** (dev.ameye.linework-lite) - обводка объектов
  - Выделение ячеек
  - Визуальная обратная связь

## 🎮 Игровые механики

### Гексагональная сетка
- Использование аксиальных координат (q, r) для представления гексов
- 6 соседей для каждой ячейки (вместо 8 в классическом сапёре)
- Динамическое определение размера поля по уровням

### Система уровней
- Прогрессивное увеличение размера поля
- Увеличение процента мин с каждым уровнем
- Плавные переходы камеры между уровнями
- Автоматическая подстройка камеры под размер поля

### Игровой процесс
- Первый клик всегда безопасен (мины размещаются после первого клика)
- Флаги для пометки подозрительных ячеек
- Автоматическое открытие безопасных зон
- Цепные взрывы при проигрыше
- Система возрождения через просмотр рекламы

## 🔧 Установка и запуск

### Требования
- Unity 2023.2.17f1 или новее
- Universal Render Pipeline 16.0.5

### Запуск проекта
1. Клонируйте репозиторий:
```bash
git clone https://github.com/Asort97/HexSapper3D.git
```

2. Откройте проект в Unity Hub
3. Убедитесь, что выбрана правильная версия Unity (2023.2.17f1)
4. Дождитесь импорта всех пакетов
5. Откройте главную сцену в `Assets/Scenes/`
6. Нажмите Play для запуска

### Сборка WebGL
1. File → Build Settings
2. Выберите платформу WebGL
3. Выберите шаблон "PluginYG"
4. Нажмите Build
